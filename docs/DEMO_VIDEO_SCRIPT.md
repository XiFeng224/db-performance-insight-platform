# 演示视频脚本

## 1. 视频时长
- **总时长**：5~6 分钟
- **建议分镜**：10~12 个场景

## 2. 视频目标
通过录屏方式，完整展示“智值守”平台在告警受理、工单闭环、应急协作、知识沉淀与复盘优化上的核心能力。

## 4. 演示场景设计

### 场景1：告警中心
- **操作**：打开平台首页，进入告警中心
- **重点展示**：告警分级、一键转工单

### 场景2：工单中心
- **操作**：查看工单详情，进行派单和状态流转
- **重点展示**：ETA、处理记录、闭环状态

### 场景3：应急协作
- **操作**：生成 Runbook，展示执行过程
- **重点展示**：步骤化处置、留痕、风险提示

### 场景4：知识库与优化建议
- **操作**：检索知识库，查看优化建议
- **重点展示**：知识沉淀、批量转工单

### 场景5：AI 助手
- **操作**：进行一次受理或问答
- **重点展示**：AI 增强、fallback 标识

## 5. 视频制作建议

### 5.1 视觉效果
- 分辨率：1920×1080
- 帧率：30fps
- 字幕：中文字幕，清晰易读
- 转场：保持简洁平滑

### 5.2 音频效果
- 旁白：清晰、专业、语速适中
- 背景音乐：轻量级，不干扰旁白
- 音效：仅在关键操作节点少量使用

### 5.3 剪辑建议
- 每个场景控制在 20~30 秒
- 重点功能优先展示
- 保留少量等待时间，避免画面过快

---

## 6. 注意事项
1. 准备好演示数据，避免视频中出现空列表
2. 提前录制一版，检查字幕是否与旁白同步
3. 若 AI 依赖网络，建议准备回退模式画面
4. 总时长尽量控制在 5~6 分钟内
