# 比赛 3 分钟演示脚本（软件应用与开发）

项目名称：**智值守 - 校园实验室智能应急协作平台**

---

## 0:00 - 0:20 项目定位
- 我们面向高校实验室场景，解决“告警分散、处置断点、复盘困难”的问题。
- 平台覆盖：告警受理、工单闭环、应急协作、知识沉淀、复盘评估。
- 核心目标：把值班从经验驱动升级为数据驱动与标准化协作。

## 0:20 - 1:20 核心闭环演示
1. 打开登录页，使用演示账号进入系统。
2. 进入告警响应中心，展示告警分级（critical / warning / info）。
3. 点击“告警一键转工单”，自动带入告警上下文创建工单。
4. 在工单中心展示状态流转：待接单 → 处理中 → 待验收 → 已关闭。
5. 展示关闭回填与评分反馈，形成完整闭环。

## 1:20 - 2:10 应急协作与SLA能力
- 在应急协作中心生成应急剧本（Runbook），展示步骤执行与操作留痕。
- 展示风险扩散预测与模板化处置建议。
- 展示 SLA 能力：超时工单自动升级高优先级，并写入责任链事件。

## 2:10 - 2:40 AI与工程可靠性
- 展示 AI 助手可用于受理、问答和交接摘要。
- 强调“双轨机制”：AI 不可用时自动回退规则引擎，业务不断线。
- 展示演示模式开关：真实数据与演示数据可切换，比赛现场更稳定。

## 2:40 - 3:00 总结
- 本项目不是单点工具，而是“告警-工单-应急-复盘”的全流程平台。
- 兼具可用性、稳定性与扩展性，可直接用于校园实验室运维协作场景。
